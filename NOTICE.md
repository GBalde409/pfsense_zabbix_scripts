# Origem do script de monitoramento

`pfsense_zbx.php` — pfSense Zabbix Interface, originalmente escrito por Riccardo Bicelli <r.bicelli@gmail.com>, projeto https://github.com/rbicelli/pfsense-zabbix-template, disponibilizado sob Apache License 2.0.

A base desta alteração foi o arquivo fornecido pelo usuário, identificado como versão 0.24.7 de 27/04/2024. Em 30/10/2026 foram alterados o agendamento e a execução do speedtest, validação/cache/concorrência, leitura de itens e algumas rotinas de correção pontual. A versão local é 0.24.7-o3.20261030.1. O autor original não é apresentado como autor ou patrocinador dessas alterações.

O conteúdo de `dhcp_leases.php`, que já existia neste repositório, não foi alterado.
